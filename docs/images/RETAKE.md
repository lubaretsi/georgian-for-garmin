# Screenshots to retake

These show the app's old UI (before 0.4.0's redesign). Each needs a new capture of the same step
in the new UI, in Georgian, on Windows 11, at the window's default size (480×720), from a build
with the thin Windows scrollbar (f7c5446 or later). Crop it like `install-windows/07-app-connect.png`,
which already shows the new UI: the title bar and the content, 480×750, without the window's border.

The whole 480×720 window fits on screen only at 100% scaling with at least 768 px of height for
it (for example a 1024×768 screen with the taskbar hidden); at 125% and up on a 768-pixel-tall
screen the app shortens the window, so the capture wouldn't show the default layout. `08`, `09`
and the video need a connected watch.
